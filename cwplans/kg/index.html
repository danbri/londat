Canary Wharf graph search

Buildings, occupants, mall units, opening hours and cited facts from the cwplans scoping data, as one RDF graph. Queries run in your browser with the Factoidal engine over a Shardborough store; the parts of the store you use are kept on this device.

engine: not loadedgraph: not loadedcache: –

Loading

The engine (about 6 MB) loads once. Each query fetches only the store blocks it needs; all of them come from this device after that.

SPARQL

Every quad is in a named graph, so wrap patterns in GRAPH ?g { … }. Prefixes s:, rdfs:, owl:, geo:, dct:, void:, prov:, cwk: (https://kgx.foaf.tv/vocab#), cwp: (https://kgx.foaf.tv/pipeline#) and id: are added for you.

Data: danbri/londat kgx (N-Quads, COTTAS, Shardborough), built by build-kgx.mjs. Each graph names its sources and licence (view "Graphs and licences"). Scoping data, not reviewed for production.
Buildings and occupants include data © OpenStreetMap contributors, ODbL. Mall units: Canary Wharf Group / Living Map, archived for reference. Engine: Factoidal.
Things, graph versions and activities have IDs https://kgx.foaf.tv/id/… (shown as id:…). The vocabulary is under the same domain (cwk: https://kgx.foaf.tv/vocab#, cwp: https://kgx.foaf.tv/pipeline#). Nothing is served at those addresses yet, so an ID or a term opens here; link to one with #e=id:….
