# Places on the globe

3D Tiles 1.1 sets of places outside the Docklands zone (OKR KR1.2 with KR2.3), made by [cwplans/tools/build-place-tiles.mjs](https://github.com/danbri/londat/blob/main/cwplans/tools/build-place-tiles.mjs) and read by [docklands/globe/places.js](https://github.com/danbri/londat/blob/main/docklands/globe/places.js). Generated by the tool's `readme` command; do not edit by hand.

Owner, 2026-10-20, on the place data: "Data - is fine for now, bring it in with subdirs and readmes and provenance clear."

## Layout

```
index.json                  the places the globe knows (read by places.js)
<id>/README.md              sources, licences, credits, hashes, operations, review status (generated)
<id>/tileset.json           3D Tiles 1.1 tileset
<id>/tiles/<l>-<x>-<y>.glb  one glTF tile per quadtree cell
<id>/features.json          text and machine interface (search, featuresAt, describeView, cards)
<id>/sources/               small committed source extracts that are inputs of an operation (open licence only)
<id>/provenance/log.json    fetch records (URL, date, SHA-256 as fetched) and dataflow activities
```

Raw downloads (OSM answers, DEM GeoTIFFs, national and GHSL zips) stay in `cwplans/data/raw/places/<id>/`, git-ignored. Catastro originals are never committed.
