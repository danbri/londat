Docklands web harvest · deep dive · 2026-10-06

Site search, opening hours and mall plans

What the SearchAction data lets us search, how opening hours differ by mall and area, and how far the data can place shops on a plan of each mall. Sources: 824 harvested pages, 374 Canary Wharf Group directory pages (Internet Archive copies), OSM and the registry.

Findings

    1. Site search (SearchAction)

    111 sites publish a schema.org SearchAction. We filled each template with "Canary Wharf", with "E14 5AB" and with a nonsense control query, and fetched each result page once (robots.txt obeyed, 1.1 s between requests to a host). A result counts only if the place query adds links or mentions that the control page does not have, because site menus and footers name Canary Wharf on every page.
