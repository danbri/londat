londat dashboard

The moving parts of the Canary Wharf / Docklands project (cwplans) on one page. Your browser checks each part when the page opens. Times are London time.

Checking…

GitHub API: without sign-in, GitHub allows 60 requests an hour for each internet address. This page makes about 5 for each check and keeps the answers in this tab for 5 minutes.

Summary

    Hourly cache runs

    The workflow cache-live.yml fetches the live state of the zone and commits cwplans/cache/latest.json. Schedule: cron 17 * * * *, each hour at 17 minutes past (UTC). GitHub can start a scheduled run late, or not at all, when it is busy.

    Checking…

    Site deploys

    The workflow pages.yml publishes the site after each push to main that changes more than cwplans/cache/.

    Checking…

    Live data freshness

    The pages read cache/latest.json before they ask a third-party service. A theme is stale when its newest fetch is more than 2 hours old.
